TypeScript desde cero: Tipos, interfaces y primeros pasos

Si ya sabes JavaScript y quieres dar el siguiente paso, TypeScript es el camino. En 2026, es prácticamente obligatorio en proyectos profesionales: React, Angular, Next.js, NestJS y Node.js lo usan de forma nativa. En esta guía aprenderás TypeScript desde cero, en español y con ejemplos prácticos que puedes probar hoy mismo.

¿Qué es TypeScript y por qué usarlo?

TypeScript es un superconjunto (superset) de JavaScript desarrollado por Microsoft que añade tipado estático al lenguaje. Esto significa que puedes declarar el tipo de cada variable, parámetro y valor de retorno, y el compilador detectará errores antes de que el código se ejecute.

Ventajas principales:

  • Detección de errores en tiempo de compilación: los errores de tipo se encuentran antes de llegar a producción.
  • Mejor autocompletado: VS Code y otros editores entienden TypeScript y te sugieren propiedades y métodos exactos.
  • Código más legible: los tipos funcionan como documentación viva. Sabes exactamente qué espera una función sin tener que leer su implementación.
  • Refactorización segura: cambiar el nombre de una propiedad o función actualiza todas las referencias sin romper nada.
  • Escalabilidad: en proyectos grandes, TypeScript evita una cantidad enorme de bugs que en JavaScript puro solo aparecerían en ejecución.

Instalación y configuración

Lo primero es instalar TypeScript de forma global:

npm install -g typescript

Verifica la instalación:

tsc --version

Para iniciar un proyecto, crea un archivo de configuración:

tsc --init

Esto genera un tsconfig.json. Una configuración básica recomendada:

{
  "compilerOptions": {
    "target": "ES2022",
    "module": "ESNext",
    "strict": true,
    "outDir": "./dist",
    "rootDir": "./src"
  }
}

Ahora crea un archivo src/index.ts:

const mensaje: string = "¡Hola TypeScript!";
console.log(mensaje);

Compílalo:

tsc

Verás que se genera dist/index.js con el código JavaScript equivalente. TypeScript desaparece en la compilación y solo queda JS puro.

Tipos básicos

TypeScript tiene varios tipos primitivos que ya conocerás de JavaScript, pero ahora los declaras explícitamente:

let nombre: string = "Ana";
let edad: number = 30;
let activo: boolean = true;
let indefinido: undefined = undefined;
let nulo: null = null;

// Arrays
let numeros: number[] = [1, 2, 3];
let nombres: Array<string> = ["Ana", "Luis"];

// Tuplas (arrays con longitud y tipos fijos)
let coordenada: [number, number] = [40.4168, -3.7038];

// Enum
enum Rol {
  Admin = "ADMIN",
  Editor = "EDITOR",
  Lector = "LECTOR"
}
let miRol: Rol = Rol.Admin;

Any, Unknown y Never

any desactiva el tipado para esa variable. Úsalo solo cuando sea estrictamente necesario, porque pierdes todas las ventajas de TypeScript.

unknown es como any pero más seguro: no puedes hacer nada con un valor unknown sin antes verificarlo.

never representa valores que nunca ocurren, como una función que siempre lanza un error.

let flexible: any = "puede ser cualquier cosa";
flexible = 42; // válido

let seguro: unknown = "no puedo usarlo sin verificar";
if (typeof seguro === "string") {
  console.log(seguro.toUpperCase()); // ahora sí
}

function error(mensaje: string): never {
  throw new Error(mensaje);
}

Interfaces y tipos personalizados

Las interfaces definen la forma de un objeto. Son la forma más común de tipar objetos en TypeScript:

interface Usuario {
  id: number;
  nombre: string;
  email: string;
  rol?: Rol;
  readonly creado: Date;
}

const usuario: Usuario = {
  id: 1,
  nombre: "María",
  email: "maria@ejemplo.com",
  creado: new Date()
};

Las propiedades con ? son opcionales. Las que tienen readonly no pueden modificarse después de creadas.

Type vs Interface

Ambos definen la forma de un objeto, pero tienen diferencias clave:

// type puede usar uniones e intersecciones
type Resultado = "exito" | "error" | "pendiente";
type ID = number | string;

// interface puede extenderse
interface Admin extends Usuario {
  permisos: string[];
}

// type también puede extenderse, pero con &
type AdminType = Usuario & { permisos: string[] };

Regla práctica: usa interface para objetos y clases, type para uniones, alias y tipos compuestos.

Funciones tipadas

En TypeScript puedes tipar tanto los parámetros como el valor de retorno:

function sumar(a: number, b: number): number {
  return a + b;
}

const multiplicar = (a: number, b: number): number => a * b;

// Parámetros opcionales y por defecto
function saludar(nombre: string, saludo: string = "Hola"): string {
  return `${saludo}, ${nombre}!`;
}

// Parámetros rest
function sumarTodos(...numeros: number[]): number {
  return numeros.reduce((acc, n) => acc + n, 0);
}

Genéricos

Los genéricos permiten escribir funciones y componentes que funcionan con cualquier tipo, manteniendo la seguridad:

function primero<T>(array: T[]): T | undefined {
  return array[0];
}

const num = primero([1, 2, 3]);      // tipo: number
const str = primero(["a", "b"]);     // tipo: string

// Interfaz genérica
interface Respuesta<T> {
  datos: T;
  exito: boolean;
  mensaje: string;
}

const respuesta: Respuesta<Usuario> = {
  datos: usuario,
  exito: true,
  mensaje: "Usuario encontrado"
};

Utility Types

TypeScript incluye tipos utilitarios que facilitan la transformación de tipos existentes:

interface Producto {
  id: number;
  nombre: string;
  precio: number;
  stock: number;
}

type ProductoParcial = Partial<Producto>;       // todas las propiedades opcionales
type SoloNombrePrecio = Pick<Producto, "nombre" | "precio">;  // solo esos campos
type SinStock = Omit<Producto, "stock">;         // todos excepto stock
type ProductosMapa = Record<string, Producto>;    // diccionario tipado

Conclusión

TypeScript hace que tu código sea más robusto, legible y mantenible. Una vez que lo adoptas, cuesta trabajo volver a JavaScript puro. No necesitas aprenderlo todo de golpe: empieza añadiendo tipos a funciones y objetos en un proyecto pequeño, y verás cómo mejora tu experiencia de desarrollo.

En 2026, saber TypeScript no es un plus, es un requisito en la mayoría de ofertas de desarrollo web. Es la inversión de aprendizaje con mejor retorno para cualquier desarrollador JavaScript.
